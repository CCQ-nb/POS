### 遇到问题
对于`prices`输出所有商品信息的功能，当在终端刚刚运行时马上输入`prices`则正常输出，
但如果在输入`prices`前已经输入过其他指令，如条码,或者`prices`自己，那么
下一次输入`prices`时会重复输出，并且重复输出的次数与当前已经执行的总指令数相等，
而且表头:

```c
Item      No. Pri.
------------------
```

不会重复输出

例如：
```c
>001
Cola      3.50
>prices
Item      No. Pri.
------------------
Cola      001 3.50
Lollopop  002 0.50
Nooddles  003 6.00
Cola      001 3.50
Lollopop  002 0.50
Nooddles  003 6.00
```

经过gdb调试，最终发现是构建`items`结构体数组的代码放到了循环之中，导致结构体重复
将代码置于循环外即可。

- `date`时间问题

原本本代码中，`date`会在每一次重启程序中初始化为`1`，题目中说明：
> 使得每次`checkout`后，销售记录能够持久化保存，并且在程序重启后可以查看当日的销售统计。
说明会有程序重启后的考察，但并没有说对`date`是否有要求

题目中`date`均为整数，如果只是理解为**程序运行时间**，那么重启后
`date`被重新初始化为`1`，这将会和已有的销售记录`data/sales.csv`冲突

所以进行修改：

```c
/*获得当前date*/
int load_max_date(void) {

    FILE *fp = fopen("data/sales.csv", "r");

    char line[MAX_LINE];
    int max_date = 0;

    /*跳过表头*/
    if ...
    
    while (fgets(line, sizeof(line), fp) != NULL) {
        ...
        char *token = strtok(line, ",");
        ...
        int d = atoi(token);
        if (d > max_date) max_date = d;
    }
    fclose(fp);
    return max_date;
}
```

该代码通过读取`data/sales.csv`中的最大日期来确定重启后的`date`
