## 遇到问题
对于`prices`输出所有商品信息的功能，当在终端刚刚运行时马上输入`prices`则正常输出，
但如果在输入`prices`前已经输入过其他指令，如条码,或者`prices`自己，那么
下一次输入`prices`时会重复输出，并且重复输出的次数与当前已经执行的总指令数相等，
而且表头:

```c
Item      No. Pri.
------------------
```

不会重复输出

例如：
```c
>001
Cola      3.50
>prices
Item      No. Pri.
------------------
Cola      001 3.50
Lollopop  002 0.50
Nooddles  003 6.00
Cola      001 3.50
Lollopop  002 0.50
Nooddles  003 6.00
```

经过gdb调试，最终发现是构建`items`结构体数组的代码放到了循环之中，导致结构体重复
将代码置于循环外即可。
