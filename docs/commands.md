# POS 命令参考

本文档列出七一一便利店 POS 系统支持的全部命令、参数格式与示例

***

## 收银员模式

### 扫描商品

| 命令 | 说明 |
|:---|:---|
| `<条码>` | 将对应商品加入购物车，数量 +1，并显示名称、单价、数量、小计 |
| `<条码1> <条码2> ...` | 一次扫描多个商品，用**空格**分隔 |
| `-<条码>` | 将购物车中对应商品数量 -1；加入库存，数量变为 0 时自动从购物车删除 |

### 查看商品

| 命令 | 说明 |
|:---|:---|
| `prices` | 查看所有商品的名称、条码、价格 |

### 购物车操作

| 命令 | 说明 |
|:---|:---|
| `print` | 打印当前购物车小票，包含商品、单价、数量、金额、总价 |
| `drop` | 清空购物车，重新开始 |
| `checkout` | 结账。打印小票，将销售记录追加写入`data/sales.csv`扣减库存，清空购物车 |

### 销售记录

| 命令 | 说明 |
|:---|:---|
| `sales` | 查看今天的销售记录与总营业额 |
| `sales <day>` | 查看指定日期（第几天）的销售记录与总营业额 |
| `newday` | 开始新的一天：日期 +1，清空当日内存统计，历史记录保留在`data/sales.csv`中 |

### 模式切换与退出

| 命令 | 说明 |
|:---|:---|
| `admin` | 进入管理员模式，需要输入密码 |
| `quit/exit` | 退出程序，退出输入密码状态 |


## 管理员模式
进入管理员模式后，提示符变为`admin>`

### 商品管理

| 命令 | 说明 |
|:---|:---|
| `setprice <条码> <新价格>` | 修改指定商品的价格 |
| `itemadd <条码> <名称> <价格>` | 添加一个新商品，初始库存为0 |
| `itemdel <条码>` | 删除一个商品 |

### 库存管理

| 命令 | 说明 |
|:---|:---|
| `restock <条码> <数量>` | 增加指定商品的库存 |
| `setstock <条码> <数量>` | 直接设置指定商品的库存 |

### 查看商品

| 命令 | 说明 |
|:---|:---|
| `prices` | 查看所有商品信息，包含名称、条码、价格、库存 |

### 返回收银员模式

| 命令 | 说明 |
|:---|:---|
| `back` | 退出管理员模式，返回收银员模式 |


## 输入说明

- **条码**: 例如 `001`、`002`。不要转换成整数，以免丢失前导零
- **价格**: 以元为单位，支持两位小数，例如 3.50、4.00。程序内部以整数分存储
- **数量**：整数，例如 10、50
- **多个条码**：用空格分隔，例如`001 002 003`
- **减号**：`-001` 表示减少购物车中 001 的数量。
- **日期**：`sales <day>` 中的 day 是程序运行的天数，从 1 开始递增。

**特殊说明：date在重启程序后会以`data/sales.csv`中的最大日期 +1 为当前日期**

## 错误提示

| 提示 | 原因 |
|:---|:---|
| `ERROR: code not found` | 输入的条码不存在 |
| `Stockerror: <条码>` | 该商品库存不足，无法加入购物车 |
| `Error: No item <条码> in cart` | 购物车中没有该商品，无法减少数量 |
| `Error: Duplicate code <条码>` |添加商品时条码已存在 |
| `Error: code <条码> not found` | 管理员操作时条码不存在 | 
| `Wrong password` | 管理员密码错误 |
| `Error: cannot open data/<file>.csv` |数据文件无法打开 |
